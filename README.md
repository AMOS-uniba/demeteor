`demeteor` is a collection of Python utilities for storing, manipulating and processing meteor data.
It also contains functions for claculating all-sky projections that are reused across various [AMOS](https://github.com/AMOS-uniba/) projects.

The name is a Slovak pun on "kde (je) meteor?" ("where (is the) meteor?"),
but I thought it also has a nice ring on its own (and it was free on pypi).

Not to be confused with [demetria](https://github.com/sesquideus/demetria/), my own library for computing with physics fields.
